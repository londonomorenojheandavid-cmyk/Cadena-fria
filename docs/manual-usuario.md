# ECS-DOC-03 · Manual de usuario (v1.0)

1. **Inicio de sesión:** identifíquese como operario o administrador.
2. **Panel de cavas:** cada tarjeta muestra temperatura y estado (verde / ámbar / rojo).
3. **Registro de producto:** seleccione especie y cava, digite peso y temperatura de ingreso; el código de lote se genera solo.
4. **Reportes y alertas:** consulte el historial de eventos con fecha, cava, temperatura y estado.
